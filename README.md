# サポートノート

複数人で共有して使うメモPWAです。参加者は全員、同じメモを読み書きします。個人のメモ帳ではなく、チームや家族などみんなの置き場という位置づけです。

オフラインで動作し、複数端末の間で自動的に同期します。

## 特徴

- **全員共有**: メモは個人ごとではなく1つの置き場を全員で読み書きする。ログイン機能やユーザーごとの権限はなく、招待リンク（またはトークン）を知っている人は全メモにアクセスできる
- **招待で参加**: 招待リンク（`#setup=トークン`）を開くだけでトークンが設定され、以降は自動で同期する。トークンの手入力は不要
- **ローカルファースト**: メモは端末内（IndexedDB）に保持。起動・検索・編集はオフラインで動き、同期は裏で走る
- **Markdownベース・画像添付・フォルダ整理・検索・全メモのエクスポート**など基本機能はフォーク元から引き継いでいる

## 構成

```
app/     フロントエンド: Vite + React + TypeScript + Dexie(IndexedDB) + PWA(自動更新)
worker/  バックエンド:   Cloudflare Workers + D1(メモ・メタデータ) + R2(画像実体)
```

## 由来とライセンス

個人用メモPWA「[tanimemo](https://github.com/tany4417-png/tanimemo)」をフォークし、複数人での共有利用向けに作り替えたものです。ライセンスは引き続き[MIT](LICENSE)です。

自分専用のCloudflareアカウントにセルフホストする詳しい手順（Node.js/Gitの準備からデプロイまで）は、フォーク元のREADME（上記リンク）を参照してください。全体の流れは同じで、`wrangler.jsonc` の `name` やD1/R2のリソース名がこのプロジェクト用に変わる点が異なります。

## 開発

```bash
# フロント: テスト・型チェック・ビルド
cd app
npm test
npx tsc -b --noEmit
npm run build

# フロント開発サーバー（http://localhost:5173、/api は 8787 へproxy）
npm run dev
```

```bash
# バックエンド: テスト
cd worker
npm test

# バックエンドのローカル起動（http://127.0.0.1:8787）。worker/.dev.vars に API_TOKEN=好きな値 を書く
npx wrangler dev

# デプロイ（app をビルドしてから worker で deploy）
cd ../app && npm run build
cd ../worker && npx wrangler deploy
```

## 注意

- 認証は長いランダムトークン1本のBearer認証です。ログイン機能・ユーザーごとの権限はありません
- 招待リンクはパスワードと同じ扱いです。渡す相手・渡し方に注意してください
- 無保証です。データはエクスポート機能で定期的にバックアップしてください
